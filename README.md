# Juste ce qu’il faut

Une petite application web autonome pour préparer une liste de courses à partir de références personnelles.

## Utilisation

Ouvrir simplement `index.html` dans un navigateur récent.

- Cliquer sur **Il en faut** pour ajouter un produit à la liste.
- Ajouter ou modifier les produits, leurs références et la quantité habituelle à acheter.
- Configurer l’adresse e-mail depuis le bouton **E-mail**.
- Cliquer sur **Préparer l’e-mail** pour ouvrir le logiciel de messagerie avec la liste préremplie.

Les produits, les photos et les préférences sont enregistrés uniquement dans le stockage local du navigateur. Aucun serveur ni compte n’est nécessaire.
